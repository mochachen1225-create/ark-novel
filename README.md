# AI 新紀元

> 投一枚硬幣，抽一個人生。

一款手機上就能玩的像素風文字冒險遊戲，也是科幻小說《AI 新紀元》的前導作品。

## 故事

2030 年。

科技公司 Helios 的創辦人 Adrian Vale 站上全球直播，宣布了三件事：
軌道上的太陽能陣列正式併網，電從此跟空氣一樣多；新的晶片量產，算力不再稀缺；
所以從今天起，**人類不需要再為了錢工作了。**

然後他說：我們可以移民火星了。

沒有貧窮、沒有工作、沒有死亡。每一個承諾都實現了，只是換了一種形式回來。

移民需要先「意識移轉」，名額依順位開放，順位由系統評估。
不是每個人都能上船。

## 你可以成為誰

一開始轉一次扭蛋，抽到誰，就從誰的眼睛看這個世界。稀有度就是登船的順序。

| 稀有度 | 角色 | 身分 |
|---|---|---|
| ✦ SSR | Adrian Vale | 51 歲・Helios 創辦人，整件事的籌劃者 |
| ✦ SSR | Darius Vey | 88 歲・卡索共和國終身總統，執政 50 年，想活到 150 歲 |
| ◈ SR | Dr. Noor Haddad | 39 歲・Helios 首席科學家，排序系統是她寫的 |
| ◆ R | Leo | 26 歲・外送員，抽中了第三階段的籤 |
| N | Ivy | 會計，順位第 3,417,902 號，預計出發時間：計算中 |

五條故事線彼此交錯。某個角色的一個選擇，會變成另一個角色的命運：
有人改了一個數字，另一個人就被推到「計算中」；
有人在名牌背面寫下一行字，另一個人會在某天把它翻過來。

## 怎麼玩

- **走動**：在畫面上按住拖曳，或直接點想去的地方
- **互動**：頭上有「！」的人和東西，走近後按右下角的按鈕；黃色箭頭指的是下一個目標
- **名詞圖鑑**：對話中藍色的字是專有名詞，會自動收進右上角的「圖鑑」
- **速度**：右上角可切換 1x／2x／3x
- **離開**：右上角的 ✕ 可以隨時回到扭蛋機
- **重玩**：玩過的章節會記住，可以「從這一幕重玩」，試試別的選擇
- **取名**：抽到角色後，可以替角色和 AI 助理取名字，或按 🎲 隨機換一個

目前共 **27 個結局**。

## 技術

- 單一 `index.html`，沒有後端、不需要建置，直接用 GitHub Pages 發布
- 畫面用 Canvas 繪製：地圖以 16×16 格子組成，角色是 32×32 的像素 sprite，光源從左上角打下來，跑步動作有 4 幀
- 音效由 Web Audio 即時合成
- 進度、結局、圖鑑、名字存在瀏覽器的 localStorage（只存在你自己的裝置上）
